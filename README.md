## ✨ Overview
Paste an HTML email fragment, render it inside a sandboxed iframe, and review practical markup checks. It does not send email or contact a mail service.

## 🚀 Features
- ✨ Render pasted HTML inside a sandboxed iframe
- ✨ Switch between desktop-width and mobile-width previews
- ✨ Flag missing viewport metadata and image alt text
- ✨ Check for images without explicit dimensions
- ✨ Keep editing and previewing in the local browser

## 🎬 Demo
Paste a template or load the included sample, then switch the preview width to inspect the layout.

## ⚡ Quick Start
```bash
npm start
# Open http://127.0.0.1:4174
```

## 🧰 Tech Stack
Node.js built-in HTTP server, HTML, CSS, and browser-native JavaScript. No external packages.
